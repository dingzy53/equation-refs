# Maxwell

Gauss's law (linked, so it gets a number):

$$
\nabla \cdot \mathbf{E} = \frac{\rho}{\varepsilon_0}
$$
^gauss

No magnetic monopoles (labelled but never linked, so no number):

$$
\nabla \cdot \mathbf{B} = 0
$$
^no-monopoles

Faraday's law (linked from this note only):

$$
\nabla \times \mathbf{E} = -\frac{\partial \mathbf{B}}{\partial t}
$$
^faraday

A manual tag is kept as is:

$$
\nabla \times \mathbf{B} = \mu_0 \mathbf{J} + \mu_0 \varepsilon_0 \frac{\partial \mathbf{E}}{\partial t} \tag{A}
$$
^ampere

Linked but marked `\notag`, so it stays unnumbered:

$$
c = \frac{1}{\sqrt{\mu_0 \varepsilon_0}} \notag
$$
^speed

A display block written on one line:

$$ \mathbf{F} = q(\mathbf{E} + \mathbf{v} \times \mathbf{B}) $$ ^lorentz
